🔒 AppHost – Lokales CA-Zertifikat

Installiere diese Zertifizierungsstelle einmalig auf deinem Gerät, damit alle *.apphost.lan-Seiten ohne Warnung als sicher gelten.

⬇️ CA-Zertifikat herunterladen

Windows (Edge / Chrome)

  1. Datei doppelklicken → Zertifikat installieren
  2. Lokaler Computer → Vertrauenswürdige Stammzertifizierungsstellen

Firefox

  1. Einstellungen → Datenschutz & Sicherheit → Zertifikate anzeigen
  2. Reiter Zertifizierungsstellen → Importieren → „Websites vertrauen" ankreuzen

Android

  1. Einstellungen → Sicherheit → Zertifikat installieren → CA-Zertifikat

iPhone / iPad

  1. Profil laden → Einstellungen → Profil geladen → installieren
  2. Einstellungen → Allgemein → Info → Zertifikatsvertrauen → aktivieren
Beim allerersten Aufruf dieser Seite warnt der Browser noch (das Gerät kennt die CA ja noch nicht) — einmal „trotzdem fortfahren", herunterladen, installieren. Danach ist überall das grüne Schloss da.
